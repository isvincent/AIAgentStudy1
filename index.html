01 / 概念定位

AI Agent 不只是會回答，而是能完成工作

以教師與行政人員的真實業務為中心，讓 AI 規劃步驟、讀取資料、使用工具、驗證產出，並交付可用的成果。真正的 Agent 必須保留人工審核與安全邊界。

03 / 大型實作

8 個最值得現場示範的進階專題

從現場 15 分鐘展示到跨系統專案，透過實作感受 Agent 的多步驟能力。

04 / 工作流

一個完整 AI Agent 的 6 個階段

研習時觀察 Agent 如何規劃、使用工具、處理例外、重試與交付，而不只觀察最後的畫面。

現場教學問題

你看到 Agent 讀取了哪些檔案？使用什麼工具？出錯時怎麼處理？最後有沒有測試？哪些步驟必須人為核可？

05 / 工具比較

Codex、Antigravity、Claude Code 怎麼教？

建議使用同一份測試資料與驗收標準，跨工具比較結果，不預設任何工具一定較好。

06 / 研習規劃器

選擇研習時間，即時調整課程

提供 2、3、6 小時示範課表，可下載文字版，作為講師備課與研習公告參考。

07 / 可複製提示詞

直接交給 AI Agent 的進階任務指令

可切換三種工作流範本；先要求規劃，再執行與驗收。
